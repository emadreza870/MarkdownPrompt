# افزونه مدیریت پرامپت هوش مصنوعی

یک افزونه کروم برای نوشتن، ویرایش و مدیریت پرامپت‌های هوش مصنوعی با پشتیبانی از ChatGPT، Gemini، Claude و Grok.

## ویژگی‌ها

- ✅ **ویرایشگر WYSIWYG پیشرفته** با امکانات کامل فرمت‌دهی متن
- ✅ **Side Panel خالص** برای تجربه کاربری بهتر
- ✅ **ذخیره خودکار** پرامپت‌ها بدون نیاز به کلیک اضافی
- ✅ **دکمه تزریق هوشمند** کنار باکس چت در سایت‌های هوش مصنوعی
- ✅ **پشتیبانی از مارک‌داون** با قابلیت کپی و دانلود فایل .md
- ✅ **تم تاریک/روشن خودکار** با امکان تغییر دستی
- ✅ **رابط کاربری فارسی** با طراحی مینیمال و دکمه‌های گرد
- ✅ **مدیریت پرامپت‌های ذخیره شده** (مشاهده، ویرایش، حذف)

## سایت‌های پشتیبانی شده

- ChatGPT (chat.openai.com)
- Google Gemini (gemini.google.com)
- Claude AI (claude.ai)
- Grok (grok.x.ai و x.com/i/grok)

## نصب افزونه

1. باز کردن کروم و رفتن به آدرس `chrome://extensions/`
2. فعال کردن **Developer mode** (حالت توسعه‌دهنده) در گوشه بالا سمت راست
3. کلیک روی **Load unpacked** (بارگذاری بسته نشده)
4. انتخاب پوشه `ai-prompt-extension`
5. افزونه نصب شد! حالا می‌توانید از آن استفاده کنید.

## نحوه استفاده

### ۱. باز کردن Side Panel
- روی آیکون افزونه در نوار ابزار کروم کلیک کنید
- Side Panel در سمت راست مرورگر باز می‌شود

### ۲. نوشتن پرامپت
- در ویرایشگر متن، پرامپت خود را بنویسید
- از نوار ابزار برای فرمت‌دهی استفاده کنید:
  - **B** - ضخیم کردن متن
  - *I* - ایتالیک کردن
  - <u>U</u> - زیرخط دار کردن
  - H1/H2 - ایجاد تیتر
  - 📊 جدول - درج جدول
  - </> کد - درج بلوک کد
  - • لیست / 1. لیست - ایجاد لیست

### ۳. ذخیره پرامپت
- پرامپت به صورت **خودکار** هر ۲ ثانیه پس از توقف تایپ ذخیره می‌شود
- یا می‌توانید روی دکمه **💾 ذخیره پرامپت** کلیک کنید

### ۴. تزریق پرامپت به صفحه چت
- پس از ذخیره پرامپت، به سایت هوش مصنوعی مورد نظر بروید
- در Side Panel، روی پرامپت ذخیره شده کلیک کنید
- متن Markdown را کپی کنید یا از دکمه‌های موجود استفاده نمایید
- دکمه **📥 پرامپت** به صورت خودکار کنار باکس چت ظاهر می‌شود
- روی دکمه کلیک کنید تا پرامپت در باکس چت تزریق شود

### ۵. مدیریت پرامپت‌های ذخیره شده
- در پایین Side Panel، لیست پرامپت‌های ذخیره شده را می‌بینید
- با کلیک روی هر پرامپت:
  - مشاهده جزئیات
  - ویرایش و به‌روزرسانی
  - کپی متن Markdown
  - دانلود فایل .md
  - حذف پرامپت

### ۶. تغییر تم
- روی دکمه 🌓 در بالای Side Panel کلیک کنید
- تم بین تاریک و روشن تغییر می‌کند
- تم به صورت خودکار با تنظیمات ویندوز شما هماهنگ می‌شود

## ساختار فایل‌ها

```
ai-prompt-extension/
├── manifest.json       # فایل پیکربندی افزونه
├── background.js       # سرویس ورکر پس‌زمینه
├── sidepanel.html      # رابط کاربری Side Panel
├── sidepanel.css       # استایل‌های Side Panel
├── sidepanel.js        # منطق Side Panel
├── content.js          # اسکریپت تزریق متن به صفحات
├── content.css         # استایل‌های Content Script
└── icons/              # آیکون‌های افزونه
    ├── icon48.png
    └── icon128.png
```

## فناوری‌های استفاده شده

- **Manifest V3** - آخرین نسخه API افزونه‌های کروم
- **Side Panel API** - برای نمایش پنل کناری
- **chrome.storage.local** - ذخیره‌سازی محلی داده‌ها
- **Content Scripts** - تعامل با صفحات وب
- **HTML5 ContentEditable** - ویرایشگر WYSIWYG
- **CSS Variables** - پشتیبانی از تم تاریک/روشن

## نکات مهم

- پرامپت‌ها فقط به صورت **محلی** در مرورگر شما ذخیره می‌شوند
- برای عملکرد بهتر، از آخرین نسخه کروم استفاده کنید
- اگر دکمه تزریق ظاهر نشد، صفحه را رفرش کنید
- برای اضافه کردن سایت‌های جدید، فایل `manifest.json` و `content.js` را ویرایش کنید
